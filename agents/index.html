Robotcyb

An open-source cosmic interface and local AI experiment linked to CicadaFarm. This static page requires no JavaScript, WebGPU or animation.

Working experiences

  • Robotcyb: interactive cosmic scene, local AI chat and external token tools.
  • CicadaFarm: interactive farm, merchant-published goods and USD-anchored CICADAFARM token checkout.
  • Public project repositories: research and development; not all repositories represent finished products.

Capabilities and limits

AI loads in the browser in a worker when WebGPU is available. A project guide is available while it loads or if unsupported. Generated replies may be inaccurate. The site does not give an agent authority to sign transactions or spend funds. The original Prophet, Lab and Action modes are conversational styles.

Cosmic scenes are visual experiments. Local sentiment votes are browser-device data, not a verified global community poll. Market/security links are external tools, not security guarantees. Farm location is private.
